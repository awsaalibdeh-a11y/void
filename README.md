# VOID

A free browser driving and flying game set in New Legion, a New York-style city built in code with three.js. Made by Legion.

**Play:** https://death242-void.static.hf.space

## What's in it
- Drive, drift, fly (the VOID car has thrusters and wings), plane, helicopter and boat
- Get out and walk, and take any car in traffic: 200 traffic models, from rusty city cars to hover cars that fly in sky lanes
- VOID Motors: 50 cars to buy with the cash you earn, plus garage upgrades
- Police chases, street races with bots, ghosts of your best runs, your own routes shared by link
- Contracts (rooftop deliveries, takedowns, drone chases, hot cargo), taxi jobs, coins, ramp tricks
- Weather, day and night, crash damage, online rooms with proximity voice chat

## Run it locally
```bash
pip install -r requirements.txt
python app.py
```
Then open http://localhost:5205.
